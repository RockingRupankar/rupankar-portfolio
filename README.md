# Rupankar Ghatak — Data Engineer Portfolio

A responsive one-page portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio content and structure
- `styles.css` — responsive visual system
- `script.js` — mobile menu, scroll reveals, dynamic year
- `Rupankar_Resume.pdf` — résumé download used by the site

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
The résumé lists LinkedIn and GitHub but does not include their full URLs. Add those URLs in `index.html` in the contact section before publishing.

## Easy hosting
This static site can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any standard web server.
